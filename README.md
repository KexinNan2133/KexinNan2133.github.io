# 快捷Excel数据处理工具

## 项目介绍
**快捷Excel数据处理工具**是一款纯前端、无服务器依赖的Excel/CSV数据处理工具，支持数据导入、清洗、条件计算、多维度分析及结果导出，所有数据仅在用户浏览器本地处理，不会上传至任何服务器，保障数据隐私安全。

核心优势：
- 📊 可视化分析：支持生成柱状图、饼图、折线图等多种图表
- 🔒 隐私安全：本地数据处理，无数据上传风险
- 🚀 轻量便捷：无需安装，通过浏览器即可使用
- 📈 功能全面：覆盖数据处理全流程，满足日常办公需求


## 功能清单
| 功能模块       | 具体能力                                                                 |
|----------------|--------------------------------------------------------------------------|
| 数据导入       | 支持Excel（.xlsx/.xls）、CSV文件上传，也可手动输入数据                   |
| 数据清洗       | 去重、缺失值处理、列类型手动转换（解决数值类型误判问题）                 |

| 结果导出       | 支持将处理后的数据导出为Excel文件                                       |

## 快速开始
### 1. 环境要求
- 浏览器：Chrome 80+、Edge 80+、Firefox 75+、Safari 14+（需支持`Blob`、`FileReader`等现代API）
- 文件要求：Excel/CSV文件需去除表头（标题行），单文件建议≤10MB（避免浏览器卡顿）


### 2. 使用步骤
#### 步骤1：导入数据
- 方式1：直接将Excel/CSV文件拖放至「上传区域」
- 方式2：点击「上传区域」选择本地文件
- 方式3：点击「手动输入数据」自行添加数据
- 提示：若Excel有多个工作表，可通过「选择工作表」下拉框切换

#### 步骤2：数据清洗（可选）
- 去重：勾选「去除重复行」，点击「执行清洗」
- 缺失值处理：选择「填充空值」或「删除空值行」，点击「执行清洗」
- 列类型转换：若数值列被误判为文本，在「列类型设置」中选择列，点击「设为数值类型」（核心优化功能）

#### 步骤3：条件计算（可选）
1. 选择计算函数（如SUMIFS、COUNTIFS）
2. 设置条件（支持多条件组合，如“列A>10 且 列B=‘北京’”）
3. 点击「预览结果」查看计算效果，确认后点击「执行计算」

#### 步骤4：多维度分析
1. 拖拽左侧字段至「行维度」（分组依据）
2. 拖拽数值字段至「值维度」（需计算的字段，若无法拖拽可先在步骤2中转换列类型）
3. 选择聚合方式（求和/平均值/计数等）
4. 点击「生成透视表」查看分析结果，也可选择图表类型（如柱状图、饼图）生成可视化图表

#### 步骤5：导出结果
- 导出数据：点击「导出Excel」，将处理后的结果保存为本地Excel文件
- 导出图表：生成图表后，点击「导出图表」，将图表保存为PNG图片


## 部署指南（本地/自有服务器）
若需在本地或自有服务器部署，而非使用GitHub Pages，可按以下步骤操作：

### 1. 本地部署
1. 克隆仓库：
   ```bash
   git clone https://github.com/你的用户名/仓库名.git
   cd 仓库名
   ```
2. 直接打开根目录的`index.html`文件（双击即可通过浏览器打开）
3. 测试功能：确保所有操作（上传、计算、导出）正常

### 2. 服务器部署
1. 将仓库中的所有文件（`index.html`、图片资源等）上传至服务器的网站根目录（如Nginx的`/usr/share/nginx/html`）
2. 配置服务器（以Nginx为例）：
   ```nginx
   server {
       listen 80;
       server_name 你的域名;
       root /usr/share/nginx/html/仓库名;
       index index.html;
       
       # 解决单页应用路由问题（若后续迭代添加路由）
       location / {
           try_files $uri $uri/ /index.html;
       }
   }
   ```
3. 重启Nginx：
   ```bash
   systemctl restart nginx
   ```
4. 访问你的域名，确认工具正常运行

## 常见问题（FAQ）
### Q1：上传文件时提示“格式错误”？
A1：请检查以下几点：
- 文件格式是否为`.xlsx`、`.xls`或`.csv`（仅支持这三种格式）
- 文件是否已去除表头（标题行），工具要求直接导入数据行
- 文件大小是否超过10MB（过大可能导致浏览器卡顿，建议拆分文件）

### Q2：数值列无法拖拽至“值维度”？
A2：这是核心优化场景，解决方案：
1. 进入「数据清洗」模块
2. 在「列类型设置」下拉框中选择该列
3. 点击「设为数值类型」，系统会强制将列类型转为数值
4. 重新回到「多维度分析」，即可正常拖拽

### Q3：生成图表后无法导出？
A3：可能是浏览器权限问题：
- 检查浏览器是否禁止了弹出窗口或下载（解除禁止后重试）
- 若使用Chrome，可在地址栏右侧「下载」图标中查看被拦截的下载

### Q4：工具运行卡顿？
A4：建议：
- 减少单次处理的数据量（建议≤1万行，过多会占用浏览器内存）
- 关闭浏览器其他标签页，释放内存
- 升级浏览器至最新版本


## 隐私说明
1. 数据处理：所有数据仅在用户本地浏览器中解析、计算和存储，不会通过网络上传至任何服务器
2. 数据存储：临时数据仅保存在浏览器内存中，关闭页面后数据自动清除，不会残留
3. 第三方依赖：使用的CDN资源（如Tailwind、Chart.js）仅用于加载工具所需样式和功能，不会收集用户数据
